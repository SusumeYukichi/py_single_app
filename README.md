# 概要

Pythonの事務作業効率化・自動化プログラム

## 目的

テキスト処理を効率的に行い,
迅速な情報整理と正確な情報伝達を実現したい.

## 効率化したい作業

- 文章の情報整理
- テキストファイルの読込と出力作業

### プログラム名

- app_01.py
- app_02.py

### ライブラリ環境

- Python 3.14.7
- pip 26.2.1
- pyperclip 1.11.0

### app_01.py 機能

- クリップボード読込
- 行頭に記号付与
- データ整形
- クリップボード貼付

### app_02.py 機能

- コマンドライン引数によるファイルパス指定
- 例外処理
- ファイル読込
- 行頭に記号付与
- データ整形
- ファイル出力
