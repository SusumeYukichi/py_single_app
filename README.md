# 概要

Pythonの事務作業効率化・自動化プログラム

## 目的

テキスト処理を効率的に行い,
迅速な情報整理と正確な情報伝達を実現したい.

## 効率化したい作業

- 文章の情報整理
- テキストファイルの読込と出力作業
- IT用語取得と整理
- 記事投稿などの外部発信
- 特定用語のデータベース管理
- 日次の共通タスク把握・追加作業

### プログラム名

- app_01.py
- app_02.py
- app_03.py
- app_04.py
- app_05.py
- app_06.py

### ライブラリ環境

- Python 3.14.7
- pip 26.2.1
- pyperclip 1.11.0

### app_01.py 機能

- クリップボード読込
- 行頭に記号付与
- データ整形
- クリップボード貼付

### app_02.py 機能

- コマンドライン引数によるファイルパス指定
- 例外処理
- ファイル読込
- 行頭に記号付与
- データ整形
- ファイル出力

### app_03.py 機能

- データ整形
- 正規表現
- 繰返処理
- データの用語化

### app_04.py 機能

- 投稿日のターミナル入力
- タイトル検証
- URL起動検証
- ハッシュタグ取得

### app_05.py 機能

- コマンドライン引数によるファイルパス指定
- ハッシュタグのデータベース登録
- 改行処理
- ファイル保存のターミナル選択

### app_06.py 機能

- コマンドライン引数によるファイルパス指定
- タスク・ライブラリのリスト参照
- 追加タスクのターミナル入力
- タスク設定日取得
- ファイル出力
